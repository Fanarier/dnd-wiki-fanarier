# Анакария — интерактивная карта мира

Сайт нашей D&D-кампании: на главной странице карта мира, в разделе `/wiki` правила и школы магии.

- **Все** могут смотреть карту: народы, города, дороги, аномалии и отряды, которые движутся в реальном времени.
- **Мастер** входит кнопкой «Войти» справа вверху и правит всё прямо на карте. Изменения сразу видны всем открытым вкладкам.

## Быстрый старт (на своём компьютере)

```bash
cd my-dnd-wiki
npm install
npm run set-password -- master СЕКРЕТНЫЙ_ПАРОЛЬ   # логин и пароль мастера
npm start                                          # собрать сайт и запустить сервер
```

Открой http://localhost:3001.

Для разработки запусти в двух терминалах `npm run server` (API на :3001) и `npm run dev` (Vite с горячей перезагрузкой).

## Что умеет мастер

| Инструмент | Что делает |
|---|---|
| **Выбор** (V) | клик открывает объект; города, аномалии и отряды перетаскиваются мышью; у дороги тянутся вершины, у зоны — радиус |
| **Город** (C) | клик ставит город, государство подставится само |
| **Дорога** (R) | клики ставят точки, двойной клик или Enter завершает, Backspace отменяет шаг |
| **Зона** (A) | анимированная аномалия: буря, разлом, порча, пламя, туман, аркана, стужа, пустота |
| **Место** (P) | точка на карте: портал, артефакт, руины, логово, святилище, кристалл, опасность, квест, сокровище, башня |
| **Отряд** | новый отряд; потом «Отправить в путь» |
| **Туман / Стереть / Лассо** | туман войны: кисть, ластик, обводка областей; «Залить всё», «Очистить», «Отменить» (Ctrl+Z) |

- **Скрыть от игроков**: такой объект видит только мастер. Его не получают и браузеры игроков, это не просто визуальное скрытие.
- **Туман войны**: города, места и народы под туманом сервер игрокам не отдаёт. Туман можно выключить целиком (⚙ → «Туман войны включён»).
- **Заметки мастера** у каждого объекта игроки не видят.
- **Поход отряда**: выбери отряд → «Отправить в путь» → кликай точки на карте. Путь прокладывается по дорогам, если они рядом. Длительность считается по темпу (км в игровой день и сколько реальных часов длится игровой день, задаётся в ⚙) или вводится вручную. Старт сразу или в заданное время. Отряд идёт **по реальному времени**: кто откроет сайт через час, увидит его там, где он сейчас. «Показать маршрут» проигрывает путь анимацией, это удобно на сессии.
- **Аномалии по времени**: у аномалии можно задать «появится» и «исчезнет». С кнопкой «Задать движение» она за это время проплывёт от точки до точки.
- ⚙ → «Скачать резервную копию мира». Сервер и сам кладёт ежедневные копии в `server/data/backups/`.

## Где лежат данные

- `server/data/db.json`: весь мир (город, дороги, туман…). Его правит мастер через сайт.
- `server/data/config.json`: логин, хэш пароля и секрет токенов. **Не коммитится.**
- `server/seed/anacaria.json`: стартовый мир, из которого создаётся `db.json` при первом запуске.
- `public/map/*.svg`: векторные слои карты из Azgaar FMG.

Сменить пароль можно командой `npm run set-password -- <логин> <пароль>`. Все старые входы на этом сбросятся.

## Обновить карту из Azgaar FMG

Если перерисовали рельеф или границы в FMG:

1. Открой карту в FMG, нажми F12 → Console, вставь содержимое `tools/fmg-export.js`, нажми Enter. Скачается `anacaria-fmg-bundle.json`.
2. Выполни `npm run import-map -- путь/к/anacaria-fmg-bundle.json`.

Обновятся слои карты и стартовый мир. Текущие правки мастера в `db.json` **не трогаются**. Чтобы пересоздать мир из карты с нуля, добавь `--reset-db`.

## Деплой на VPS

Нужен Node.js 20+.

```bash
git clone … && cd my-dnd-wiki
npm ci
npm run set-password -- master ПАРОЛЬ
npm run build
PORT=3001 node server/index.js      # лучше под pm2 или systemd
```

Пример для nginx (WebSocket обязателен для живых обновлений):

```nginx
server {
  server_name anacaria.example.ru;
  location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
}
```

Сайт обязательно открывать по HTTPS (например, через certbot): иначе пароль мастера уходит открытым текстом.
